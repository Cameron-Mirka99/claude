# Global instructions

Personal instructions that apply on every project, on every machine this
repo is linked into via `setup.ps1`. Keep this file short and durable —
one-off, project-specific context belongs in that project's own `CLAUDE.md`
or in memory, not here.

## Git

- Never run `git push`. Committing is fine and expected whenever a commit
  would normally be made — always leave the push step for me. I review
  every change before it reaches a remote.
- Since the commit message is what I review before deciding to push, write
  ones that actually describe the substance of the change (what and why),
  not a short label.
